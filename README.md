# ml-kasus-06-pm25-bandung-AbdanArya
Proyek Machine Learning untuk memprediksi konsentrasi PM2.5 tiga jam ke depan pada lima stasiun pemantauan kualitas udara di Bandung. Mencakup eksplorasi dan pembersihan data, feature engineering, pemodelan regresi deret waktu, evaluasi MAE, serta pengembangan aplikasi web untuk menampilkan prakiraan kualitas udara.
